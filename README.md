# NASA-client (web)

The web version of [NASA-client](https://github.com/web-prj/NASA-client), NASA's
Astronomy Picture of the Day app, so it can run on an iPhone.

**Open it:** https://nam-antoine.github.io/nasa-client/

On iPhone, open the link in Safari, then tap Share → **Add to Home Screen**.

Plain HTML, CSS and JavaScript with no libraries. Favorites are saved in the browser
(`localStorage`). It uses NASA's `DEMO_KEY`, which allows only a few requests per hour;
put your own free key from <https://api.nasa.gov> at the top of `app.js`.
